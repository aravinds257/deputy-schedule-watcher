How to Obtain Your Deputy Bearer / Permanent Token

1
Log in to your Deputy account

Log in with your Deputy email and password at your organization's URL (e.g. https://a2c28219075424.uk.deputy.com).

2
Open Developer / API Access Page

Navigate directly in your browser to:
https://a2c28219075424.uk.deputy.com/exec/devapp/oauth_clients

(Or navigate via Deputy Profile Menu → Account Settings → Developer Tools / API)

3
Generate / Copy Permanent Bearer Token

Click on "Get an access token" or "Permanent Token". Copy the long token string and paste it into this app.

Security Notice: The token is saved strictly in your local browser storage. It allows fetching only your authorized shifts and schedule data.
